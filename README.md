# Mouse Tea — мод для Minecraft Forge 1.20.1

Добавляет предмет **«Мышиный чай»** (`mousetea:mouse_tea`). При выпивании игрок
постепенно превращается в антропоморфную мышь:

| Стадия | Что происходит |
|---|---|
| 0 | Обычный игрок |
| 1 | Появляются уши (растут прямо на голове, поворачиваются вместе с ней) |
| 2 | + Хвост (крепится к спине/пояснице) |
| 3 | + Усы, лёгкий бонус к скорости и прыжку |
| 4 | Финальная стадия: бонус к сытости, максимально "мышиный" вид |

Каждый выпитый глоток чая продвигает игрока на одну стадию вперёд. Прогресс
сохраняется между смертями и перезаходом (хранится в capability на игроке
и синхронизируется всем, кто видит игрока, чтобы уши/хвост отображались
и от третьего лица).

## Важно: что я не могу сделать в этой песочнице

У меня нет доступа к интернету и к самой Minecraft/Forge в этом окружении,
поэтому:

- Я **не собирал и не запускал** мод — Gradle при сборке скачивает Forge
  и Minecraft (десятки–сотни МБ), а сеть здесь отключена.
- Текстуры (`mouse_tea.png` и `mouse_parts.png`) — это **простые
  процедурные заглушки**, сгенерированные скриптом `gen_textures.py`
  (розовая мышиная кожа, набросок ушей/хвоста/усов). Они рабочие
  (правильный размер и прозрачность), но не художественные — замените
  их своими через Blockbench/любой редактор PNG, сохранив те же
  UV-координаты, либо переразверните модель в Blockbench заново.
- Модель ушей/хвоста/усов сделана простыми кубами прямо в коде
  (без .json-модели/Blockbench) — этого достаточно для рабочего мода,
  но геометрия базовая. Собственный "отдельный скин" в вашем понимании —
  это как раз файл `mouse_parts.png`: можно дорисовать в нём мех, полоски,
  розовые лапки и т.д., координаты кубов в `MouseAddonModel.java` покажут,
  какая область текстуры на какую грань идёт.
- Крафт-рецепт (`data/mousetea/recipes/mouse_tea.json`) — упрощённый
  (зелье воды + сахар + пшеница → чай), чисто чтобы предмет можно было
  получить в выживании. Настройте под себя.

Иными словами: код целостный и должен собираться и работать на Forge
1.20.1 "из коробки", но **вам нужно собрать его на своей машине** (с
интернетом) и проверить в игре — я не могу это протестировать за вас.

## Самый простой способ получить jar — без установки Java/Gradle (GitHub Actions)

В архиве уже лежит `.github/workflows/build.yml`. Он соберёт мод в облаке —
вам не нужно ничего ставить локально:

1. Создайте пустой репозиторий на https://github.com (можно приватный).
2. Загрузите в него содержимое папки `mousetea` (через веб-интерфейс
   "Add file → Upload files" — можно перетащить все файлы и папки — либо
   через `git push`, если умеете).
3. Откройте вкладку **Actions** в репозитории — сборка запустится
   автоматически при пуше (или нажмите "Run workflow" вручную).
4. Дождитесь зелёной галочки (обычно 3–7 минут — качается Forge/Minecraft).
5. Откройте завершённый workflow-run → внизу раздел **Artifacts** →
   скачайте `mousetea-jar.zip`. Внутри будет ваш `mousetea-1.0.0.jar`.

Это реально рабочий способ получить готовый jar, вообще не устанавливая
JDK/Gradle на свой компьютер.

## Как собрать локально

Нужны: **JDK 17**, интернет (Gradle скачает Forge MDK 1.20.1-47.2.0).

```bash
cd mousetea
./gradlew build          # на Windows: gradlew.bat build
```

Готовый джар появится в `build/libs/mousetea-1.0.0.jar` — киньте его
в папку `mods` клиента/сервера с установленным Forge 1.20.1.

Для теста прямо из исходников:

```bash
./gradlew runClient
```

(Gradle wrapper-файлы `gradlew`/`gradlew.bat`/`gradle/wrapper/*` я не
генерировал — при первом открытии проекта в IntelliJ IDEA с плагином
Forge/Gradle они создадутся автоматически, либо выполните
`gradle wrapper --gradle-version 8.1.1` вручную.)

## Как настроить под себя

- **Скорость превращения**: сейчас 1 стадия = 1 выпитый чай (мгновенно
  по завершению анимации питья). Если хотите растянуть по времени —
  добавьте в `CapabilityEvents.onPlayerTick` проверку `ticksInStage`
  и вызывайте `data.advanceStage()` там же, а не в `MouseTeaItem`.
- **Внешний вид**: правьте `mouse_parts.png` и координаты кубов в
  `MouseAddonModel.createLayer()`.
- **Полная замена модели на финальной стадии** (не только уши/хвост,
  а полностью другой силуэт): в `MouseFormLayer.render()` на
  `stage >= MouseFormData.MAX_STAGE` можно скрывать `getParentModel()`
  через `player.isInvisible()`-подобный трюк или банально прятать
  `getParentModel().getHead()/getBody()` (`.visible = false`) и рисовать
  вместо них свою полноценную модель — заготовки под это в текущем
  коде нет, это следующий шаг, если захотите пойти дальше "надстройки"
  к ушам/хвосту.
